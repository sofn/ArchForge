# Preferences — how this project's owner likes work done

- Plan first, execute after approval (`AGENTS.md` workflow). Non-trivial work gets a `.agents/changes/` dir.
- Evidence over claims: report real commands + trimmed output, not "should work".
- Commits: no `Co-Authored-By` lines. English commit messages, conventional style.
- AI-facing files (`.agents/`, AGENTS.md, commands, memory): **English only**.
- Cross-repo work: touch other repos only when explicitly required; state it in the plan.
