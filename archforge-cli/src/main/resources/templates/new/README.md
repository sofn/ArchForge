# %NAME%

Spring Boot 4 application scaffolded by `archforge new`.

## Quickstart

```bash
./gradlew build
./gradlew bootRun
```

## Structure

| Path | Purpose |
|---|---|
| `src/main/java` | application code |
| `archforge-module-*/` | business modules (`archforge module new <name>`) |
| `archforge/` | Project Definition — file-first metadata |
| `spec/` | API contract |
